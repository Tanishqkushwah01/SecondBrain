## 🌟 Overview

Every day we consume dozens of valuable resources:

🎥 YouTube Tutorials

🐙 GitHub Repositories

💼 LinkedIn Posts

📚 Documentation

📝 Blogs & Articles

💡 Learning Resources

Unfortunately, most of them get lost in browser bookmarks, chats, notes, or history.

**Second Brain** solves this problem by creating a centralized place where all your important resources live forever.

Think of it as your digital memory.

## ⚡ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/second-brain.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
